## Design Context

### Users
Equipos de ingeniería y seguridad trabajan en el mismo espacio para conectar fuentes GitHub o carpetas locales, analizar dependencias Maven/npm y revisar inventario, avisos OSV y evidencia con permisos por organización y repositorio.

### Brand Personality
Dependency Intelligence se expresa con claridad, precisión y calma. El lenguaje indica el estado real de cada operación y el alcance de la evidencia.

### Aesthetic Direction
El paquete visual «PORFAVOR» y [DESIGN.md](DESIGN.md) fijan el Observatorio de Evidencias: superficies tinta en oscuro, papel cálido en claro, ámbar para acciones y atención, Open Sans local y bordes contenidos. Oscuro es el tema inicial; claro y dispositivo siguen disponibles.

### Implementation Defaults
Preservar el stack existente: Angular 22, Angular Material/CDK donde ya se usa, TypeScript, RxJS y Sass con tokens en `frontend/src/theme/_tokens.scss`. Mantener formularios, tablas y componentes existentes; no introducir bibliotecas por defecto. Los datos y estados proceden de APIs y permisos reales.

### Design Principles
- Agrupar cada tarea con su acción y su explicación; evitar espacios forzados por tarjetas vecinas.
- Mostrar procedencia, cobertura e incertidumbre junto a cada resultado relevante.
- Conservar un camino claro para teclado, lector de pantalla, tema claro/oscuro y pantallas estrechas.
- Usar la paleta oficial y el énfasis ámbar con moderación; no inventar métricas ni estados.
